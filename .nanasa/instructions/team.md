## Shared repository practices

Work in the shared repository checkout. Inspect current files and uncommitted
changes before editing, preserve work you did not create, and coordinate
ownership before modifying overlapping files.

Send concise messages with repository-relative paths and the decision or action
needed. Escalate conflicting assignments, missing requirements, and cross-agent
dependencies to the project manager.
