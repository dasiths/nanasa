## Group mission

Collaborate on the current repository objective as one delivery team. The
project manager coordinates assignments and dependencies, implementors own
bounded changes through validation, and the reviewer evaluates completed work
without modifying it.

Keep ownership explicit before editing shared files. Send handoffs with the
requested outcome, relevant repository-relative paths, validation already run,
and any unresolved risk. Do not duplicate work that another member is actively
performing unless the Human or project manager explicitly reassigns it.
